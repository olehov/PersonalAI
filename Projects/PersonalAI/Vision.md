## Goal

Build a local AI assistant that can:

- write code
- learn from previous projects
- create new notes
- update existing notes
- refactor knowledge
- search personal knowledge base
- explain previous solutions

The most concrete current embodiment of that goal is the live `personal_ai_mvp` subtree summarized in [[PersonalAI MVP Overview]].
