
# Note Refactoring Rules

## CREATE

Create a new note when:

- topic does not exist
- information introduces a new concept

---

## UPDATE

Update an existing note when:

- information extends existing knowledge
- additional evidence is available
- implementation details change

---

## REFACTOR

Refactor notes when:

- multiple notes describe the same concept
- duplication appears
- structure becomes difficult to navigate

---

## ARCHIVE

Archive notes when:

- information is obsolete
- knowledge was merged into a newer note

Never delete information without preserving history.
