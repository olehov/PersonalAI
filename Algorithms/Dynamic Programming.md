# Dynamic Programming

## Basics
Dynamic programming solves problems by breaking them into overlapping subproblems, storing intermediate results, and reusing them instead of recomputing them.

## Core Ideas

- optimal substructure
- overlapping subproblems
- memoization or bottom-up tabulation

## Common Workflow

1. Define the state.
2. Define the recurrence.
3. Set base cases.
4. Choose memoization or tabulation.
5. Recover the final answer from the computed states.

## Tradeoffs

- often improves time complexity significantly
- may increase memory usage
- state definition is usually the hardest part

## Examples

- Fibonacci
- knapsack
- longest common subsequence
