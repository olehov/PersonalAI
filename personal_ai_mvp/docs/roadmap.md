# Roadmap

## Current Direction

PersonalAI is already beyond a toy prototype, but it is still moving toward a more production-like coding assistant experience.

## Near-Term Priorities

- simplify the frontend UX
- strengthen runtime recovery and health handling
- improve agent execution reliability
- expand benchmark coverage
- continue documentation cleanup

## Longer-Term Themes

- more trustworthy multi-step coding assistance
- stronger repo-aware automation
- richer benchmark-driven iteration loops
- better separation between developer diagnostics and end-user product UX

## Planning Source

The active Scrum-style planning source remains the PersonalAI delivery note maintained in the knowledge graph.
